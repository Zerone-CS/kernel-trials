## 尚未验证或不提供的保证

- 没有正式账号/OS 沙箱，不能用于敌对 Agent 的可信排名。
- 原生 CLI 实机验收覆盖 Claude Code；其他适配器通过参数和流程单元测试，未逐一完成实机 NPU 验收。
- 其他 NPU、CANN/驱动组合需新环境验证和重新标定；公开仓库不携带通用可用的标定时间。
- 计量协议要求一次调用对应一个 device compute task，不支持任意多 kernel 的可信总耗时归属。
- 当前不是完整统计推断工具；少量重复、单算子和重叠场景标签不能支持广泛能力或显著性结论。
- 原生 Windows、所有 WSL 环境、长时间稳定性与所有崩溃恢复组合未验收。
- 本机 Ctrl-C 或 SSH 断连不保证远端 Agent 停止；未知执行状态需要人工确认。

发布新的验证结论时，应附代码版本、题包/协议/基线/环境身份、完整计划与全部结果，并遵守 [实验规范](EXPERIMENT_SPEC.md) 和 [报告规范](REPORT_SPEC.md)。原始日志不宜直接公开，脱敏也不得删除失败 trial 或改变数值。
